# Getting Started

Each guide on this site walks through integrating one piece of testing into a project, step by step.

> Guides are added over time. Pick one from the sidebar to begin.

## How to follow a guide

1. Read the **Prerequisites** section first.
2. Run each command in order. Use the **Copy** button on code blocks.
3. Check the **Verify** step at the end of each section before moving on.

## Example

```bash
npm install --save-dev vitest
npx vitest run
```
